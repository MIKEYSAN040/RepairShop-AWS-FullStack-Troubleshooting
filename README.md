# Repair Shop Application – AWS Support Project

A full-stack repair shop application deployed on AWS and used to demonstrate **hands-on Cloud Support and troubleshooting skills**.

## Architecture

**React Frontend -> Amazon S3 -> Amazon EC2 (Node.js/Express) -> Amazon RDS MySQL**

## Technology Stack

* **Frontend:** React, Vite, JavaScript
* **Backend:** Node.js, Express, REST API
* **Database:** Amazon RDS MySQL
* **AWS:** S3, EC2, RDS, Security Groups, CloudWatch
* **OS / Support:** Amazon Linux, systemd

## What I Implemented

* Deployed a customer-facing React application on Amazon S3
* Deployed a Node.js REST API on Amazon EC2
* Connected the backend to a private RDS MySQL database
* Configured EC2–RDS network access using Security Groups
* Implemented backend service management using systemd
* Performed end-to-end application validation

## Cloud Support Troubleshooting

 Resolved **5 realistic production-style incidents**:

 Incident-01-Backend Service Stopped                - Linux / systemd              
 Incident-02-Database Connectivity Failure          - Security Groups / Networking 

 Incident-03-API HTTP 500                           - Database Configuration       
 Incident-04-Frontend–Backend Failure               - CORS / API Connectivity      
 Incident-05-Service Failure After EC2 Reboot       - Service Persistence          

## Support Workflow

**Customer Impact -> Investigation -> Root Cause -> Remediation -> Recovery Validation**

## Key Skills Demonstrated

**AWS, Linux, Networking, API Troubleshooting, Database Connectivity, Security Groups, Configuration Troubleshooting, Log Analysis, Incident Response, Root-Cause Analysis, End-to-End Validation**

## Project Outcome

Built and supported a working AWS-hosted application while demonstrating the ability to **investigate customer-impacting issues, identify root causes, apply fixes, and validate service recovery.**
